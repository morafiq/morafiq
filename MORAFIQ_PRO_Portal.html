هذا الفضاء منفصل عن الموقع العام، ومخصص لإدارة الملفات التربوية والمقابلات والمتابعة المهنية وفق صلاحيات محددة.

واجهة أولية – غير مفعّلة بعد
تنبيه حماية: لا تُدخل حالياً أسماء التلاميذ أو بياناتهم أو محاضر المقابلات. لم يتم ربط هذه الواجهة بعد بمصادقة حقيقية أو قاعدة بيانات محمية. وجود صفحة منفصلة أو إخفاء رابط لا يُعدّ حماية أمنية.

ملفات التلاميذ

مساحة مخصصة للبيانات التربوية الضرورية، لا تظهر إلا للمستخدمين المخولين.

المقابلات المهنية

سجل سري للمقابلات والملاحظات والتوصيات وخطط المتابعة.

نتائج الاستبيانات

عرض النتائج بموافقة مناسبة، مع تجنب استخدامها كتشخيص أو تصنيف ثابت.

إدارة الصلاحيات

ربط كل مستخدم بمركزه ودوره ونطاق الملفات المسموح له بالاطلاع عليها.

متطلبات التفعيل قبل استقبال أي بيانات حقيقية

  1. تفعيل Supabase Auth والتحقق من البريد وإجراءات استعادة الحساب.
  2. تحديد الأدوار: مدير النظام، مدير المركز، المستشار، والولي.
  3. تطبيق Row Level Security على كل جدول، مع اختبار منع الوصول المتبادل بين المراكز.
  4. حفظ الوثائق في مخازن خاصة مع سياسات وصول مقيّدة وروابط مؤقتة عند الحاجة.
  5. تسجيل عمليات الاطلاع والتعديل والتصدير، ووضع سياسة احتفاظ وحذف للبيانات.
  6. اختبار الصلاحيات بحسابات منفصلة قبل الإطلاق.
